# ⚜️ Sistema de Emisión de Condecoraciones y Certificados

Aplicación web desarrollada con **Streamlit** y **Python** para emitir condecoraciones oficiales de forma automática, manteniendo intacto el diseño y membrete institucional.

## 🚀 Características
- **Fidelidad al 100%:** Conserva los formatos y certificados oficiales sin alterar tipografías, sellos ni márgenes institucionales.
- **Formulario Inteligente:** Solo requiere el Nombre del galardonado, Cédula de Identidad, Código de registro y Lugar/Fecha.
- **Gestión de Firmantes:** Permite registrar autoridades con sus cargos y firmas digitales (PNG transparente) para colocarlas a la izquierda o derecha según corresponda.
- **Gestión de Formatos:** Sube nuevas plantillas PDF de condecoraciones (Oro, Plata, Bronce, etc.) de manera sencilla.
- **Vista Previa Inmediata:** Genera una previsualización gráfica y descarga directa en formato PDF listo para imprimir.

## 💻 Instalación y Ejecución Local
```bash
pip install -r requirements.txt
streamlit run app.py
```
